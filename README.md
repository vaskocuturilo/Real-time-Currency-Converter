## Real‑time Currency Converter Extension  (Chrome/Firefox/Edge)

A lightweight browser add‑on that instantly transforms any currency value on a webpage into the one you prefer. It detects amounts automatically, applies live exchange rates, and updates conversions in place—making price comparison and international browsing effortless across both Google Chrome, Firefox and Edge.

### How it works.
- This extension helps users convert one currency to another in real-time mode.
