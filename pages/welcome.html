🚀 Get Started with Real Time Currency Converter

Choose the method that works best for you:

✍️ Method 1: Manual Add (Instant)

Have a specific name in mind? Add it directly.

  1. Open the extension popup by clicking the 🧩 black icon with a short currency name (In the lower right corner)
  2. Type the amount with currecny name or icon into the input field.
  3. Currency conversion will be performed automatically.

✏️ Method 2: Highlighting Mode (Visual)

Choose conversion currency from the drop-down list

  1. Find your amount with currency on the browser page highlight it.
  2. It will appearhint with the amount that was converted.

📂 Extension supports all currencies in the world

Works with all types of data provision:

  1. 1000 EURO -> 1000€ -> 1000 Euro.
  2. 1K Euro -> 1K - 2K € -> 1k - 2k Euro.
  3. 1000 евро -> 1K - 2K ЕВРО -> 1k - 2k Евро.
